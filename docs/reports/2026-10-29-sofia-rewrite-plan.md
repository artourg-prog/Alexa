# Sofia 0.40 — voice/UI replacement and release candidate

Owner authorizes independent implementation, testing and publication of the Sofia rewrite, preserving the current package, signer, existing private API configuration and durable queues. Claude builders are unavailable; no new builder, paid Actions workflow or production-data test was used. Baseline 0.32/d5ea856 remains the rollback source. Updated behavior is recorded in SOFIA_RULES.md.

## Implemented

- Replaced the Android SpeechRecognizer restart loop with one app-owned local PCM stream, full EN/RU Vosk streaming models and bounded Whisper Base Q5_1 backup wake verification. The name-only grammar was removed after a negative fixture exposed false activation. Whisper verifies a candidate name; it cannot execute business actions. Its scheduler is muted during dialogue/TTS and does not accumulate an audio backlog. Model/vendor downloads are checksum pinned; source/licenses and reproducible fetch/fixture scripts are included, large blobs ignored.
- Owner-requested tap-to-talk is the default: a visible daytime resume or Listen tap opens a conversation; the chime waits for microphone readiness. Capture stops between conversations and on pause. The app releases its screen-on flag after conversation/cards/confirmation end, using the phone's existing timeout and AOD/wake settings. Automatic counter-opening alarms are canceled in this mode. Continuous foreground listening is an explicit alternative. Actual Samsung AOD/double-tap configuration and battery consumption have not been measured/configured here.
- Visible partial/final transcript, explicit microphone/processing/offline states, EN/RU dialogue, delayed incomplete-command prompts and worker/number context across segments. Short digit fragments join while a number is awaited. New words extend the silence window; a decoder segment does not reset the conversation. Helpful local hear-me/identity/thanks replies remain.
- Pure conversation reducer distinguishes lookup, finished-work recording and saved-report inquiry. Questions/negation cannot mutate even with an incorrect optional model suggestion. Names/numbers must be spoken/current and approved; uncertain receipt digits prompt repetition. A missing number after a report question remains a report question, not readiness or recording.
- Save-first existing Reader contract, same-event SMS yes/no, silence/no preserving work, idempotent repeat-event reuse and durable-before-send guard. Storage and delivery executors are separated so an old network retry cannot delay local persistence. Unreadable queues are preserved with a persistent review warning. Delivery chimes use tablet ADDED / SMS SENT acknowledgements, not optimistic queueing.
- Lookup cards retain stable browsing, amount, customer, readiness and red unpaid / white paid states. Not-ready expiry is 10s, ready expiry 60s. Expiry never confirms pickup or changes a different selected receipt. Explicit pickup retains exact-receipt five-second Undo. Work recording clears lookup cards. Male voice assignment is only for not-ready; actual installed target TTS voices require device acceptance.
- Two English example phrases per core workflow. UI avoids redundant redraws; night ticks are slower. There is no claim that emulator behavior proves battery savings.

## Verification

- 131 JVM tests pass, including report/lookup/write separation, split speech/digits, SMS approval, persistence failures/restart/retry, corrupt-queue recovery, card lifetimes and private finite-token validation.
- Seven Android instrumentation cases were exercised on an isolated ARM64 Android 15 emulator: four UI/lifecycle/tap-mode cases, one native streaming suite and two Whisper suites. Final UI rerun passes all four after making the test clock deterministic; an earlier wall-clock-dependent UI assertion failed when actual shop-closing time passed. Native/Whisper suites pass on the final application APK. No production credentials are on the emulator.
- Audio consists only of synthesized EN/RU synthetic receipt numbers, deterministic 15 dB SNR noise, negative speech and a 30-second silent lead-in. Native suite also exercises 12 fresh decoder lifetimes per language. An earlier combined run aborted in Vosk native lattice handling; decoder reset/reuse during mute was removed in favor of fresh decoders over retained models. Subsequent native/stress and UI runs pass; this is not a guarantee about all physical microphone conditions.
- Optional semantic-worker schema/privacy/auth/negation/question tests pass. A synthetic model trial misclassified negated work; independent server/phone guards reject it. Raw audio, real worker names, receipt numbers and unknown words are not exported to this optional service.
